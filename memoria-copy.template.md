# Memória de copy

> Copie este arquivo para `memoria-copy.md` na primeira sessão e preencha conforme as sessões acontecerem. É lido antes de escrever e atualizado depois de entregar.
>
> **Por que este arquivo existe.** A skill proíbe inventar número, depoimento, prazo e credencial — o que significa que ela tem que pedir esses fatos ao usuário. Sem memória, ela pede **os mesmos fatos do mesmo produto em toda sessão**, e o usuário paga um turno de perguntas para cada peça. Aqui cada fato é fornecido uma vez.
>
> **A regra que faz o arquivo valer algo é a origem.** Fato sem origem marcada é fato sem procedência, e fato sem procedência volta para a copy como afirmação — exatamente o que a proibição de inventar fato existe para impedir. Um arquivo de memória sem disciplina de origem é pior que nenhum, porque lava suposição em duas sessões: você presume hoje, lê como dado amanhã.

## 2. Fatos verificados

A seção mais importante do arquivo. Cada linha carrega **origem e data**, e a marca decide o que pode ser afirmado:

- `[FORNECIDO]` — o usuário afirmou. **É o único nível que pode ser afirmado na copy.**
- `[PRESUMIDO]` — você inferiu do contexto. Continua valendo placeholder marcado (`[nº real de alunos]`), nunca afirmação.

| Fato | Valor | Origem | Data | Marca | Vence? |
|------|-------|--------|------|-------|--------|
| | | | | | |

**A coluna `Vence?`** existe porque preço, número de alunos, prazo de turma, vaga restante e resultado de aluno mudam. Fato marcado como perecível é **reconfirmado com o usuário antes de voltar para a copy** — fato antigo afirmado como atual é fato inventado com data de validade vencida, e a escassez que era real na sessão passada é escassez falsa nesta. Cialdini veta as duas do mesmo jeito.

## 4. Resultados de teste

O único dado de eficácia que existe. Sem esta seção, o assento de Caples no conselho é retórica: ele pergunta "você acha ou você testou?" e não há onde consultar a resposta.

| Data | Peça | Canal | Apelo usado | Métrica | Resultado | Contra o quê |
|------|------|-------|-------------|---------|-----------|--------------|
| | | | | | | |

**"Contra o quê" é obrigatório.** Resultado sem comparação não é resultado: 3% de CTR não significa nada sem a variante ou o histórico ao lado. Quando o usuário trouxer só o número absoluto, registre e marque `sem comparação` — vale menos, mas vale mais que nada, e deixa claro que vale menos.
